butone VPN для Windows 11
=========================

1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Запустите ButoneVPN.exe.
3. Подтвердите стандартный запрос контроля учётных записей Windows.
4. Нажмите большую кнопку «ВКЛЮЧИТЬ».

Приложение создаёт системный VPN-туннель: через него проходит трафик всех
программ Windows. Российские сайты, банки, Госуслуги, Яндекс, VK и основные
маркетплейсы направляются напрямую.

Не переносите один ButoneVPN.exe отдельно: рядом должны оставаться mihomo.exe
и папка bundle. Обновлённые списки и отчёты хранятся в:
%LOCALAPPDATA%\butone-vpn

Если Windows SmartScreen покажет предупреждение, это связано с отсутствием
платного коммерческого сертификата подписи Windows. Исходный код приложения
и процесс сборки опубликованы в репозитории проекта.
